# Reference screenshots

Reference only. Nothing in this folder ever ships in the clone.

Empty on purpose: this recon ran in a sandbox that cannot open campus.coach or
the app stores, so no screenshots were taken. To fill it, take screenshots by
hand from the public App Store / Google Play listings, or from your own account
at human speed. Name them after their screen ID, like `S07-week-view.png`, so
`/replica-diff` can match them.
